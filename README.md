# swiggy_sql

🚀 Advanced SQL Project – Swiggy Deep-Dive Analysis 🍽️📊

Thrilled to share my latest project where I conducted an in-depth SQL analysis of Swiggy, India’s leading food delivery platform. 
This project demonstrates how relational database systems and advanced SQL can fuel data-driven decision-making in the fast-paced food tech industry.

📘 Project Objective

To explore customer behavior, restaurant performance, delivery trends, and location-based insights using complex SQL queries and structured datasets.

📌 Key Focus Areas

👤 Customer Analytics: Order frequency, inactivity, unique behavior patterns
🍴 Restaurant Metrics: Revenue generation, average ratings, top performers
🚴‍♂️ Delivery Trends: Partner efficiency, customer reach
🏙️ Location-Based Insights: City-specific behavior and marketing potential
⏱️ Order Timeline: Recent activity and time-based logistics

💡 Insights Delivered

1. Identified inactive and high-frequency customers to tailor engagement
2. Ranked restaurants by revenue and rating to inform platform promotion
3. Mapped delivery efficiency for operational optimization
4. Analyzed patterns to boost retention and targeted campaigns

🧠 Tech Stack: MySQL, Advanced SQL Functions
